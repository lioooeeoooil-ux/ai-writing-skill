# Pattern Bank（可复用招式库）

> 从 exemplars 蒸馏的**可迁移件**：结构模板 / 风格参数 / 口语骨架。只收招式，不收原句（仓库边界：他人内容不照抄）。
> 用法：起草每章前按参考库协议对号，进口 1-2 件，起草说明里对账。

## 行文结构

- **时间线踩坑型**（作者A）：动机 → 预期 → 翻车 → 归因 → 可复用清单；段落配比约 1:1:3:1:1，重心压在翻车复盘。
- **概念拆解型**（作者A/作者B）：现象 → 旧框架失效 → 新框架 → 交付物；可配编号小节。
- **故事先行型**（作者A）：完整叙事开场（可含截图）→ 概念解释 → 方法收束。

## 风格参数

- 数字密度：每 200-400 字一处具体数字/编号/题号（作者A级）。
- 段落：主体 2-5 句；连续两个 5 句以上长段必须插短段。
- 粗体：全文级节点才加粗，一段至多一处；满屏粗体等于没有。

## 口语骨架（可迁移句式）

- "丑话说在前面：……"
- "先说结论：……"
- "这不是 X，是 Y。"
- 收束 callback："如果……再发一条只有自己看得懂的状态：……"

## 诚实披露三件套（作者A）

现场 → 决策（含"不修/放弃"类）→ 理由公开。凡放弃类决策标配，是人味的主要来源。
